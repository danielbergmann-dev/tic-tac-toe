# FÜNFZEHN

Mobiles Zahlen-Tic-Tac-Toe gegen die KI. Eine Reihe, Spalte oder Diagonale aus drei Zahlen mit Summe 15 gewinnt.

- Du: 2, 4, 6, 8; KI: 1, 3, 5, 7, 9
- Startspieler wählbar
- Drei Schwierigkeitsstufen
- Verfügbare und verbrauchte Zahlen sichtbar

## GitHub Pages

Unter Settings → Pages: Deploy from a branch, Branch `main`, Ordner `/ (root)`, Save.

## Lokal starten

`python3 -m http.server 8000` im Projektordner ausführen und http://localhost:8000 öffnen.

Die App benötigt keinen Serverdienst und keinen API-Schlüssel. Die KI läuft direkt im Browser.
